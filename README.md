# EduVia – AI-Powered Learning Platform

## Overview
This project was developed as part of the FullstackJS – 4th Year Engineering Program (TWIN) at **Esprit School of Engineering** (Academic Year 2026).

EduVia is an intelligent platform that personalizes education using AI. It adapts to each student’s level, helping them learn faster and avoid failure.

## Features
- AI-generated quizzes
- Personalized learning paths
- Course recommendations
- Early detection of struggling students
- Real-time assistance
